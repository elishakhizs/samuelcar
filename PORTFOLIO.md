# Samuel Car — Portfolio Project

## Full-Stack Laravel Competition & E-Commerce Platform

### Overview

Samuel Car is a full-stack web application developed with Laravel to support an online car competition and merchandise platform.

The application combines competition management, ticket purchasing, skill-based free-ticket functionality and e-commerce features within a single web application.

### My Role

Full-Stack Developer

I was responsible for designing and developing the application, including the backend, database, frontend interfaces, competition functionality, ticket system, shopping basket and merchandise management.
